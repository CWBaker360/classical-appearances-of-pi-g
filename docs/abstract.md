# Abstract

This note records representative classical formulae in which the usual
constant \(\pi\) is rewritten as a geometric limiting constant \(\pi_g\).
Once a prior geometric argument establishes \(\pi_g=\pi\), every exact
occurrence of \(\pi\) may be equivalently written as \(\pi_g\).

The note emphasizes the distinction between the completed exact constant
\(\pi_g\) and finite approximants \(\pi_g^{(N)}\). A numerical illustration
uses polygonal N-series acceleration and a Gaussian normalization calculation.
